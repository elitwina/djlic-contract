# הסכמי התקשרות – DJ LIC

אפליקציית ווב ליצירת הסכם התקשרות, שליחתו ללקוח בוואטסאפ וחתימה דיגיטלית.

**כתובת:** https://elitwina.github.io/djlic-contract/

## איך זה עובד
1. נכנסים עם הסיסמה (נשמרת במכשיר) ורואים את כל ההסכמים והסטטוס שלהם.
2. "הסכם חדש" – שאלה אחת בכל מסך, חתימה, תצוגה מקדימה.
3. "שליחה ללקוח בוואטסאפ" – מקלידים מספר, בוחרים מאנשי הקשר (אנדרואיד) או בוחרים איש קשר בתוך וואטסאפ.
4. הלקוח פותח קישור קצר, ממלא שם/ת״ז/טלפון, מאשר וחותם, ושולח את העותק ל-052-2967041.
5. ההסכמים נשמרים בגיליון Google של הבעלים, והקישור עצמו הוא העותק של כל צד. "שמירה כ-PDF" מפיקה עמוד A4 אחד.

## מבנה
- `app.js` – הממשק: כניסה, רשימת הסכמים, אשף, תצוגה מקדימה, עמוד חתימה, עותק חתום.
- `lib.js` – פונקציות טהורות (טלפון/ת״ז, דחיסת חתימה, תאריכים).
- `backend/Code.gs` – השרת (Google Apps Script שמוצמד לגיליון). הגרסה עם קוד הבעלים האמיתי
  נמצאת ב-`backend/Code.private.gs` ולא נשמרת ב-git.
- כתובת השרת מוגדרת ב-`CONFIG.apiUrl` בתוך `app.js`.
- טקסט ההסכם נמצא ב-`CLAUSES` בתוך `app.js`.
- בדיקות: `node --test test/` (כולל הרצה של `Code.gs` מול סביבת Google מדומה).
