# הסכמי התקשרות – DJ LIC

אפליקציית ווב קטנה ליצירת הסכם התקשרות, שליחתו ללקוח בוואטסאפ וחתימה דיגיטלית.

**כתובת:** https://elitwina.github.io/djlic-contract/

## איך זה עובד
1. פותחים את הכתובת ועונים על השאלות (פרט אחד בכל מסך) וחותמים.
2. בתצוגה המקדימה לוחצים "שליחה ללקוח בוואטסאפ" ומקלידים את המספר.
3. הלקוח פותח את הקישור, משלים פרטים חסרים, חותם, ושולח את העותק החתום ל-052-2967041.
4. כל פרטי ההסכם והחתימות נמצאים בתוך הקישור עצמו – ההודעה בוואטסאפ היא העותק של כל צד.
   אין שרת ואין מסד נתונים. "שמירה כ-PDF" מפיקה עמוד A4 אחד.

## פיתוח
- `lib.js` – פונקציות טהורות (קידוד הקישור, אימות טלפון/ת״ז, דחיסת חתימה).
- `app.js` – הממשק: אשף, תצוגה מקדימה, עמוד חתימה, עותק חתום.
- בדיקות: `node --test test/`
- טקסט ההסכם נמצא ב-`CLAUSES` בתוך `app.js`.
